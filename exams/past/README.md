## Adding a paper

File it under the academic year it was sat: `exams/past/<YYYY>-<YYYY>/`. Use
`midterm.pdf`, `final.pdf`, `makeup.pdf`. If it is somebody's answered paper rather
than a blank one, it belongs in `terms/<year>-<term>/submissions/` instead.
