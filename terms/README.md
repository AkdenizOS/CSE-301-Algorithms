# Terms

One folder per cohort. Everything that belongs to a single run of the course —
that term's syllabus, slides, labs, assignments, personal notes and submissions —
lives in its own folder and stays there.

## Adding your term

```
terms/2026-2027-fall/
├── README.md      instructor, assistant, schedule, exam dates, whose work this is
├── syllabus.pdf
├── slides/
├── labs/
├── assignments/
└── notes/         your own week-by-week notes, if you keep them separately
```

Write the README first. A folder of files with no attribution is much less useful
to the next person than a folder with three lines saying who made it and when.
