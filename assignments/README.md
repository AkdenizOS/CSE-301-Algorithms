# Assignments

Coursework that somebody produced: assignments, projects, lab solutions, submissions.
Your own work goes in `assignments/<term>-<you>/` (for example
`assignments/2026-2027-fall-efe-kurucay/`, with a `labs/` subfolder for lab work).
Material whose author is not known goes in `assignments/<term>-unattributed/`.

Use a lowercase, hyphenated folder name — `efe-kurucay`, not `Efe Kuruçay`.

**Exam papers do not go here.** A midterm or final — blank or somebody's graded
answers — is study material, so it lives in [`../exams/<YYYY>-<YYYY>/`](../exams/README.md)
where anyone preparing for an exam will look.

Previous students' submissions are here as **reference**, not as answers to copy —
see [Academic integrity](../README.md#academic-integrity).
